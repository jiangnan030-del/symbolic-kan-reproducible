# Contributing

Contributions are welcome, subject to two non-negotiable rules:

1. Preserve the upstream attribution, MIT notice, original repository URL, and audited commit.
2. Never label modified results as results of the original paper.

Algorithm changes and code-organization changes should be submitted separately. Every
behavioral change should include a test and document whether it affects `legacy`, `paper`,
or `corrected` profiles. Please use focused commits and record the exact configuration and
random seed for numerical claims.
